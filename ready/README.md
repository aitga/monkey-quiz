Put your finished videos (made with Argon or any app) in this folder.

- Name them so they sort in order: 01-morocco.mp4, 02-morocco.mp4 ...
- Optional caption: a .txt file with the same name (01-morocco.txt).
- Each day the robot posts your videos from here first, then deletes them from this folder.
- If this folder is empty, the robot makes its own quiz videos automatically.
