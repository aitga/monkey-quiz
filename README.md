# Monkey Unleashed – daily history quiz videos

Every day GitHub makes new quiz videos from `quizzes.json`, waits for your approval, then posts them to YouTube, Facebook, Instagram, TikTok and X.

- **Add quizzes:** edit `quizzes.json`. Put the RIGHT answer first in `options` (the video mixes the order).
- **Videos per day:** change `videos_per_day` in `config.json`.
- **One country per week:** the countries go in the order they appear in `quizzes.json`.
- **Your monkey:** upload your monkey picture as `images/monkey.png` (a PNG with a see-through background looks best).
- **Your own background pictures:** upload `images/<landmark-name>.jpg`, e.g. `images/hassan-ii-mosque.jpg`. Otherwise a real photo of the landmark is taken from Wikimedia Commons (credited in the video).
- **Approve posts:** Actions → today's "Daily monkey quiz" run → Review deployments → approval → Approve and deploy.

## Privacy

This project only posts videos to the account owner's own social media accounts. It does not collect or store anyone's personal data.
